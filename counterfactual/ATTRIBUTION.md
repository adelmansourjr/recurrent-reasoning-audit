# Does the structured answer copy the worked example?

Specified after inspecting the same-cohort format follow-up, where most valid outputs reproduced its worked example, and before scoring the independent attribution cohort. Use seed 426001, the existing generator, and the first four questions of every shuffled family-by-alias cell, giving 32 fresh problems. Verify that no original problem text overlaps the earlier 64-item cohort. The inputs for each item are fixed and balanced across eight cells.

Use the same existing checkpoint, closed thinking section, output prefix, 40-token cap, greedy decoding and batch width at most eight. Compare three versions of the same structured prompt. Demonstration A is the existing example with program [2,-1,0,1]. Demonstration B reverses only the credit/debit directions in the same demonstration, with the mathematically correct opposite program [-2,1,0,-1]. The zero coefficient stays zero. The no-example control keeps the full format instruction and assistant-side prefix. Each item sees every version, with alternating arm order by batch. Both reference demonstrations differ from every gold program. Apart from the demonstration, the tested question, model and extractor are fixed.

Count verbatim copies of A and B, executable outputs and exactly grounded programs in all arms. Test the paired gain in A-copying under demonstration A and in B-copying under demonstration B. Use a two-sided exact paired sign test on discordant questions and a stratified paired bootstrap using the existing 5,000 draws. The planned practical bar is that each demonstration produces at least 50% incorrect copies of its own answer, and shifts copying toward its own answer by at least 30 percentage points versus the other demonstration, with lower paired interval above zero. The no-example control assesses whether a fixed output format alone gives the same response. Record accuracy and real tokens as secondary outcomes. This tests sensitivity to a specific prompt choice and says nothing about the general effect of few-shot demonstrations.
